# Stock Portfolio Tracker

A Python-based stock portfolio tracker built in Jupyter Notebook (Anaconda-friendly) for beginners learning financial data handling with Python.

## Overview
The project helps you:
- Add multiple stocks to a portfolio
- Track quantity and purchase price
- Fetch current stock prices (using `yfinance` when available)
- Calculate total investment value
- Calculate current portfolio value
- Calculate profit/loss and profit/loss percentage

## Technologies Used
- Python
- Jupyter Notebook
- Anaconda
- Pandas
- NumPy
- yfinance (optional, for live prices)

## How to Run
1. Install Anaconda (or ensure Python with Jupyter is available).
2. Open Jupyter Notebook.
3. Open `Stock_Portfolio_Tracker.ipynb`.
4. Run all cells.

## Example Output
- Total Investment Value
- Current Portfolio Value
- Profit / Loss
- Profit / Loss Percentage
