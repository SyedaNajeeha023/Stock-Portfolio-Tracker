# Stock Portfolio Tracker
## Overview

The Stock Portfolio Tracker is a Python-based project developed using Jupyter Notebook in Anaconda. It allows users to track their stock investments, calculate total portfolio value, and monitor profit or loss based on current market prices.
This project demonstrates the use of Python for financial data analysis and portfolio management.

## Features

* Add multiple stocks to a portfolio
* Store quantity and purchase price
* Fetch current stock prices
* Calculate total investment value
* Calculate current portfolio value
* Compute profit and loss
* Display results in a structured format

## Technologies Used

* Python
* Jupyter Notebook
* Anaconda
* Pandas
* NumPy

## How It Works

* The user enters stock symbols, quantity, and purchase price.
* The program retrieves the latest stock prices (if using an API such as yfinance).
* It calculates:

  * Total investment amount
  * Current portfolio value
  * Overall profit or loss
* Results are displayed in tabular format.
